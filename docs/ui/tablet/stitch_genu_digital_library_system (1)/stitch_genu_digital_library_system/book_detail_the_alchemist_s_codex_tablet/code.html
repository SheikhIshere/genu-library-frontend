Recovered from the subterranean cloister of the Benedictine abbey near Nuremberg, this definitive volume compiles the comprehensive metallurgical theorems, furnace schematics, and celestial transmutations attributed to Eberhardt of Mainz (c. 1484). Hand-inscribed in iron gall ink on double-sized rag vellum, every plate exhibits exquisite woodblock illuminations hand-painted with cinnabar, lapis lazuli, and genuine hammered gold leaf.
